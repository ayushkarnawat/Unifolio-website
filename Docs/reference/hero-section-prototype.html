How it works

The hero stays the same piece of the page: the sketch animation, the button and the cycling highlight block keep their behaviour and timing. Only the words and the six highlight states change, with the spacing adjusted for the longer text.

Headline
“Your family’s wealth, understood.” replaces “See everything you own. Understand what it means.” (page 4 copy; the page 3 mockup still shows the old words).
Line under it
“All your family’s investments. Deeper insights. Smarter decisions.” replaces “Track. Understand. Act with confidence.” It is bigger and bolder as the PDF asks (style A: larger, bold, dark).
Highlight block
Six states (page 5) instead of three. Same behaviour as today: each slides in, its key words get a green underline, it holds a moment, then slides out to the next. Every state stays for 3 seconds, on desktop, tablet and phone. Each state has its own small, quiet animation: three account chips (funds, stocks, bank) curving into one ring that fills up green as each arrives, data travelling to a locked store, a performance line drawing past a dashed benchmark, an access toggle switching off, a green highlighter scanning along five holdings one by one, and a small marker that hops one stone at a time along a path, each stone lighting green, until it reaches a flag. Use the Highlight switch to hold any one state.
Spacing
The block is positioned exactly like the current one: under the button, nudged down 64px on desktop and tablet-wide layouts, centred under the button on narrow screens, with the same extra gap on phones (44px) and the same text sizes as the current hero. The headline, line and button keep their place. It has a fixed height so nothing jumps when the states change (it is taller now because the sentences are longer).
Tablet
Same as the site today: the full-height hero with the sketch in the upper part and the text, button and highlight block centred at the bottom.
Phone
Same as the site today: the sketch on top, then the text centred below.

Where the PDF disagrees with itself (what I used)

  1. Headline and linePage 3 (the design) still shows “See everything you own. Understand what it means.” and “Track. Understand. Act with confidence.” Page 4 (copy) changes both. I used page 4.
  2. State 4The copy says “(mention about DPDP act)” as a note, not as final words. I wrote “Built for India’s DPDP Act.” at the end, matching the Security section.
  3. State 2It talks about both encryption in transit and at rest, which used to be two separate states. I show both in one picture: data travelling to a store that locks.
  4. IllustrationsThe PDF says illustrations are indicative, so the small pictures in each state are mine, drawn in the same sketchy style as the rest.
  5. Page 3 mockupThe pill navigation and the storyboard picture are unchanged, so they are not repeated here (only the storyboard is shown).
