  3. Benefits 1 and 2Mockup: "Get early access to Unifolio" and "Be the first to know about new features". Copy page: "Be first to try Unifolio" and "Hear about new features". I used the copy page.
  4. Privacy lineMockup: "We respect your privacy. No spam, ever." Copy page: "Your information stays private. No spam." I used the copy page.

Questions before I build this

  1. Email subject line and preview text. The PDF does not give them. My suggestion: "You're on the Unifolio waitlist" with the preview "Your early access pass is inside."
  2. Spot number. The pass shows "#1". Should it be the person's real position in line (as the current email does), and is "Priority: Early Access" the same for everyone?
  3. Success auto-close. Today the pop-up closes itself after about 3 seconds. The new success screen has a "Back to home" button, so I would remove the timer and let the person close it. Is that right?
  4. Phone field. The mockup labels it "(optional)". It is already optional in the form, so I will just show the label. Confirm.
  5. Invite a friend. It goes to the website with a quiet referral code, as planned before. Still the plan?
  6. Tablet and phone designs. The PDF only shows desktop, so the tablet and bottom-sheet versions above are my proposals. Do they work?
